# 美股价值投资Agent - 云上版

随时查看方案

## 一键部署
1. Fork此仓库到你的GitHub
2. Settings -> Pages -> Source: main / docs
3. Actions -> Run workflow 手动跑一次
4. 你的仪表盘地址: https://你的用户名.github.io/value-agent-cloud/

## 每周六早上9点墨尔本时间自动更新

## 手机查看
把Pages链接添加到手机主屏幕，就是App了

## 本地测试
pip install -r requirements.txt
python main.py
open docs/index.html
